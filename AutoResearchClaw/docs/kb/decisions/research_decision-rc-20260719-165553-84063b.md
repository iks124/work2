# Stage 15: Research Decision

## Decision

REFINE

## Justification

当前结果仅能证明工程链路基本可用，尚不足以支持论文级结论。PROCEED 的最低质量标准未全部满足：

- 各条件只有 1 个 seed，低于至少 3 个 seed 的要求。
- 分析质量评分为 3/10，低于 4/10。
- Signed Top-2 与 Hard Top-2 的多项逐条件结果完全相同，消融完整性存在疑问。
- CaRE 与 basis 方法结构不对称，Sparse 与 Dense 也未公平匹配参数容量或实际延迟。

这些问题主要属于实验设计、机制激活和公平归因不足，尚未证明核心假设从根本上错误，因此应选择 REFINE，而不是 PIVOT。

## Evidence

- 已有至少两个基线及 proposed method 的结果，但全部来自单 seed（1993）、单类别顺序和每阶段 1 epoch。
- 主要指标尚未正式冻结；建议将 Final Accuracy 定义为主指标，单位为百分点，越高越好。
- CaRE 的 Final Accuracy 为 89.70%，Signed Top-2 为 83.91%，差距 5.79 点；但 CaRE 独有 shared adapter，无法将差距归因于 memory 机制。
- Signed 与 Hard 的 Task-0、Final 和 Average 完全相同，分别为 88.42%、83.91% 和 86.165%，需要排除配置未生效、日志复用或机制未激活。
- Signed 相对 Dense 的 Final Accuracy 仅高 0.17 点，远小于当前设计能够可靠解释的范围。
- Sparse 与 Dense 的解析 active FLOPs 相同，但微基准延迟分别为 0.753 ms 和 0.533 ms；当前 Sparse 约慢 41%。
- 结果质量评分仅为 3/10，且没有独立重复，无法估计方差、置信区间或统计显著性。

## Next Actions

1. 将 Final Accuracy 明确定义为主要指标，并冻结指标计算、数据划分和配置选择流程。
2. 运行最小归因实验：no adapter、shared only、basis only、shared+basis，并保留原始 CaRE 作为锚点。
3. 对 Hard Top-2 rank-16 执行 shared adapter × scale 的 2×2 实验，确保 shared adapter 与 CaRE 在结构、插入位置、初始化和优化设置上同构。
4. 检查 Signed 与 Hard 的 checkpoint 哈希、路由槽位、负权重比例、adapter 输出及反事实输出，排除配置或日志复用。
5. 记录 adapter/残差范数比、路由熵、槽位负载、dead-slot 比例、各模块梯度范数及旧新类 logit 偏置。
6. 使用独立 validation split 调参；测试集不得用于选择 scale、rank、槽数或 checkpoint。
7. 配置冻结后，至少运行 3 个训练 seed，并优先扩展为 3 seeds × 3 个固定类别顺序。
8. 基础接口校正后，再进行等 stored parameters 和等端到端 latency 的 Sparse–Dense 对比。
9. 仅当消融完整性得到验证、分析评分达到至少 4/10，且所有条件完成至少 3 个 seed 后，重新评估是否 PROCEED。
